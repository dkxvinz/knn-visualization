K-Nearest Neighbors Visualization

จำลองกระบวนการทำงานของ KNN Classification (Interactive Step-by-Step Visualization)

แนวคิด: KNN เป็น Supervised Machine Learning สำหรับการจำแนกประเภทข้อมูล (Classification) โดยพิจารณาจากข้อมูลที่มีคุณลักษณะใกล้เคียงที่สุดจำนวน K จุด (Neighbors) คำนวณระยะห่างด้วย Euclidean Distance แล้วโหวตเสียงข้างมาก (Majority Vote) เพื่อกำหนดคลาสให้กับข้อมูลชุดใหม่
