🔍 Machine Learning Visualization: K-Nearest Neighbor (KNN)

📌 อธิบายกระบวนการทำงานของ KNN (K=3)

  • Input Data: ข้อมูลมี 5 มิติ นำมารับการลดมิติด้วย PCA เพื่อพล็อตลงบนกราฟ 2D
  • Test Instance: จุดดาวสีทอง คือจุดข้อมูลทดสอบ [5, 5, 5, 5, 5]
  • Euclidean Distance Calculation: คำนวณระยะห่างระหว่างจุดทดสอบกับทุกจุดใน Training Data
  • Majority Voting: เลือกเพื่อนบ้านที่ใกล้ที่สุด 3 อันดับแรก (เส้นประ) และโหวตคำตอบ ➡️ ได้ผลลัพธ์เป็น Class B
